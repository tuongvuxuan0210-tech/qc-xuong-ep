Hạng mục kiểm tra Nội dung chi tiết cần kiểm tra Đánh giá Ghi chú
1. Cơ khí & Bề mặt • Lòng khuôn (Cavity/Core): Không trầy xước, dính nhựa, rỉ sét, bẩn.
• Dẫn hướng: Guide pins/ống dẫn (không trầy, khô dầu, tiếng kêu).
• Sliders/Lifters: Trơn tru, không bavia, công tắc hành trình OK.
2. Hệ thống làm mát • Đường ống & khớp nối: Không rò rỉ, gãy khớp nối nhanh, nghẹt.
• Nhiệt độ khuôn: Lưu thông đều, đạt nhiệt độ kỹ thuật.
3. Hệ thống đẩy SP • Ty đẩy (Ejector pins): Không cong vênh, gãy, kẹt.
• Hành trình: Bàn lừa tiến/lùi về sát vị trí ban đầu (về 0).
• Bôi trơn: Mỡ chịu nhiệt đầy đủ.
4. Hệ thống rót nhựa • Bạc cuống phun (Sprue bushing): Không mòn, xước, bám nhựa cũ.
• Hot runner/Kênh dẫn: Gia nhiệt, đầu heater, cảm biến nhiệt đủ/ổn định.

Webhook Đồng Bộ Drive & Zalo: 

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    if (data.action === 'upload_to_drive') {
      var rootFolderId = data.folderId || '1m8rzMVgucC2DT9o_2lYGjBb5tuwrX8no';
      var rootFolder = DriveApp.getFolderById(rootFolderId);
      var targetFolder = rootFolder;
      
      // Tự động tạo thư mục con (ví dụ: 'Màn hình HMI') nếu có
      var subfolderName = data.folderName || data.subfolder || data.targetFolder;
      if (subfolderName) {
        var folders = rootFolder.getFoldersByName(subfolderName);
        if (folders.hasNext()) {
          targetFolder = folders.next();
        } else {
          targetFolder = rootFolder.createFolder(subfolderName);
        }
      }
      
      var decoded = Utilities.base64Decode(data.fileData);
      var blob = Utilities.newBlob(decoded, data.mimeType || 'image/jpeg', data.fileName);
      var file = targetFolder.createFile(blob);
      file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
      
      var res = {
        status: 'success',
        fileId: file.getId(),
        fileUrl: file.getUrl(),
        folderId: targetFolder.getId(),
        folderUrl: targetFolder.getUrl()
      };
      return ContentService.createTextOutput(JSON.stringify(res)).setMimeType(ContentService.MimeType.JSON);
    }
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({ status: 'error', message: err.toString() })).setMimeType(ContentService.MimeType.JSON);
  }
}
